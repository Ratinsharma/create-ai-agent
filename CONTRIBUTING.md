# Contributing

Thanks for improving create-ai-agent.

## Ground rules

- Keep the recipe production-shaped: verification, checkpoints, skill employees — no vibes-only loops.
- Prefer small PRs (one template tweak, one scaffold fix, docs).
- Do not invent APIs or scaffolder flags that `scripts/scaffold_agent.py` does not implement.

## How to contribute

1. Fork and branch from `master`.
2. Change `SKILL.md`, `templates/`, `scripts/`, or docs.
3. If you touch the scaffolder, run it once locally and paste the generated tree in the PR.
4. Open a Pull Request.

## Issues

Use `.github/ISSUE_TEMPLATE/` for bugs and feature requests.
